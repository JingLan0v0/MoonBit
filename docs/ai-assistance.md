# AI 辅助与参赛者说明

本项目使用 AI 辅助进行需求细化、接口设计、MoonBit 代码、测试、独立参考校验及文档编写。AI 的输出经实际编译与运行验证，测试失败项修正后复测；没有把生成代码未经验证直接当成成品。

原始目标由参赛者确定：优先完成一个可运行、可测试、可维护的项目，申请本期月度支持。主办方是否认可、是否通过和是否发款由官方审核决定。

参赛者在提交前需要实际运行主样例，并能够说明：

1. 为什么按主键对应记录能消除行重排噪声。
2. 为什么重复主键要失败而不能覆盖。
3. 为什么 `001` 与 `1`、`1.0` 与 `1.00` 不应自动视为相同。
4. 引号状态机如何处理逗号、双引号和跨行字段。
5. 组合主键如何使用长度前缀避免拼接碰撞。
6. 退出码 0/1/2 和文件大小限制分别意味着什么。
7. 哪些逻辑在 MoonBit，哪些只是 Node.js 的系统接口。

当前记录不能替代用户实际理解情况。用户尚未确认完成讲解演练，提交前仍需执行这一步。
